## Evaluation criteria

Choose a search provider using measured relevance, exportability, and operating cost. Run the same query set against each candidate and keep raw results for later review.

| Criterion | Weight | Evidence |
| --- | ---: | --- |
| Relevance | 40% | Blinded query evaluation |
| Data portability | 25% | Tested export and restore |
| Operational support | 20% | Failure exercise |
| Cost | 15% | Usage-based forecast |

## Decision

Defer selection until the export exercise passes. A fast prototype is insufficient evidence for a multi-year commitment.
