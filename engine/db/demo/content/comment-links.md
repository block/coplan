# Link selected text in comments

Choose Add comment, type `hi`, and select the word. Press Cmd+K on Mac or
Ctrl+K elsewhere. A floating link picker opens beside the visible draft. Search for
"Hampton" to link a profile, or paste a URI. Enter `https://example.com/search?q=)` and choose Insert link. The draft
now contains a Markdown link; submit the comment to see the clickable label.
Try `codex://threads/example` as an application link too.
Escape or Cancel link returns to the unchanged draft. Undo reverses insertion.

Also try selecting `Use [draft` or `Path \[draft] (notes)`. Brackets and
backslashes stay in the posted label. Pasting a plain URL over a selection
links it immediately. The same controls work in replies and Edit comment.
