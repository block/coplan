Open **Edit** and drop an image and a text file into the document. Images appear inline; other supported files become download links. You can also paste an image file from your clipboard.

## Drop files here

Drop the same file twice. Each drop inserts an embed, but **Attachments** keeps one stored copy and the editor says the existing file was reused. Rename the local file and drop it again: identical contents keep the original filename, uploader, and URL.

Different contents stay separate, even with the same filename. Reuse is limited to this document. Previously stored duplicates are preserved so their saved links keep working.

## Keep writing

Continue typing during an upload. Its marker stays at the drop location. **Done** waits for uploads and saves the embedded content. **Dual** shows the image or link in Markdown. **Undo** removes an embed while leaving the file in Attachments for reuse.

Try images, PDF, text, Markdown, CSV, JSON, or ZIP files up to 25 MB each. Unsupported files show an error without discarding your writing or the accepted files.
