The title is the first heading of this document. Edit it just like the body.

## Try a rename

1. Choose Edit and change the title.
2. Wait for autosave, then type some more. The URL stays the same.
3. Choose Done. The URL adopts the final title; the original link still works.

## Try the title boundary

Backspace at the start cannot remove the title block. Its heading level is fixed. Enter moves into the body. You can erase the title text while writing; Done fills an empty title with Untitled.
