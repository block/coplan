## Rule precedence

Apply item-level discounts before order-level discounts. Tax uses the discounted taxable amount. Refunds use the original ledger receipt rather than recalculating against today's rules.

## Worked example

| Step | Amount |
| --- | ---: |
| Basket subtotal | $50.00 |
| Loyalty discount | −$5.00 |
| Taxable subtotal | $45.00 |
| Tax at 8% | $3.60 |
| Total | $48.60 |
