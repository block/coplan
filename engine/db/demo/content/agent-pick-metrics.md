## Measure a useful first week

Track the first document, the first reviewer invitation, and the first reply. Document count alone rewards writing without collaboration.

| Metric | Interpretation |
| --- | --- |
| First reply within 24 hours | The team found a useful reviewer |
| Second visit by reviewer | The review loop stayed active |
| Decision recorded | The discussion changed the plan |

Keep the cohort definition fixed while comparing onboarding changes.
